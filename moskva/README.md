# Москва — зона соавтора

## Трогай только это
- moskva/data.js — места, маршрут, подборки, конфиг города
- moskva/index.html — тексты страницы (заголовки, описание выпуска)

## Не трогай (сломается Новосибирск)
- ../index.html, ../css/*, ../js/app.js, ../js/data.js
- ../CNAME — в нём домен, удалишь и сайт отвяжется
- ../.nojekyll

Движок общий. Всё, что нужно городу, задаётся данными.

## Задача
Довести Москву до 25–30 проверенных мест. Сейчас 10 черновиков (draft:true).
Проверил место ногами или по официальному сайту — ставишь draft:false,
свою дату в checked и источник в src. Пока draft:true, на карточке висит штамп «Черновик».

## Схема места
~~~js
{
 id:'gorky',                 // латиницей, уникальный, не менять после публикации
 name:'Парк Горького',
 cat:'Погулять',             // Погулять | Поесть | Вдвоём | С детьми | Поработать | Необычное | Полезное | Активно
 shape:'feature',            // feature | tall | std | wide | note | mini — размер карточки в ленте
 area:'Якиманка',            // район, подставится слово «район»
 tags:['walk'],              // walk | eat | work | two — для чипов и подборки «сегодня»
 company:['two','kids'],     // two | friends | kids | solo
 mood:['quiet'],             // quiet | unusual | active
 indoor:false,               // true = под крышей (фильтр «Погода»)
 draft:true,                 // true = штамп «Черновик»
 lead:'Короткая подпись',    // одна строка, до 60 знаков, для карточки
 desc:'Полный текст.',       // 2–3 предложения, конкретика: что делать, сколько, где
 minus:'Один честный минус.',
 budget:[0,0],               // [мин,макс] на человека; null если непонятно; [0,0] = бесплатно
 budgetText:'Бесплатно',     // как показать человеку
 best:'Будни утром',         // лучшее время
 feat:['туалеты','Wi-Fi'],   // особенности через запятую
 hours:'24',                 // '24' | 'afisha' | {o:10,c:21,off:[1]}  off: 0=вс … 1=пн
 hoursText:'10:00–21:00, пн — выходной',
 addr:'ул. Крымский Вал, 9',
 lat:55.7294,lng:37.6013,    // координаты: Яндекс Карты → правый клик по точке → «Что здесь?»
 checked:'2026-11-20',
 src:'Проверка редакции'     // или «Уточнено по телефону», «Сверено с сайтом»
}
~~~

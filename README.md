# Месте4ко

Городской журнал о местах: подборки под ситуацию, описания с честным минусом,
реальный бюджет, дата проверки и карта. Ванильные HTML/CSS/JS без сборки,
из внешнего только Leaflet (карта) и Google Fonts.

## Структура

~~~
index.html        Новосибирск
css/              общий дизайн: base / layout / components
js/app.js         общий движок: фильтры, лента, карта, окна, фото
js/data.js        данные Новосибирска + CITY
moskva/           Москва: своя страница и свои данные
photos/           свои фотографии
CNAME             домен, НЕ УДАЛЯТЬ
.nojekyll         НЕ УДАЛЯТЬ
~~~

## Кто что трогает
- Владелец — index.html, css/, js/app.js, js/data.js
- Соавтор — только moskva/

Движок читает конфиг CITY из данных города: название, центр карты, зум,
подпись редакции, статьи Wikipedia для фото. Города не мешают друг другу.

## Локально

~~~bash
open index.html
open moskva/index.html
~~~

## Работа вдвоём

~~~bash
git pull --rebase
git add -A
git commit -m "что сделал"
git pull --rebase
git push
~~~

git add -A — когда правишь общие файлы (это твой случай).
git add moskva — только для соавтора, он сидит в своей папке.
Каждый пуш в main сразу обновляет живой сайт на домене.

## Данные
Схема полей места — в moskva/README.md, одинаковая для обоих городов.
draft:true показывает штамп «Черновик», пока место не проверено.
